# Аудит тестировщика по backlog: что не доделано

Дата: 2026-05-27
Проверяемые источники:
- `backlog/quick-wins/backend.md`
- `backlog/quick-wins/frontend.md`
- `qa/backlog-verification/status-matrix.md`
- `qa/backlog-verification/test-checklist.md`
- `qa/backlog-verification/verification-report.md`
- `qa/reopen/backend-reopen-list.md`

## 1) Противоречивые выводы в QA-артефактах

- В `qa/backlog-verification/status-matrix.md` backend-задачи `BE-01..BE-08` отмечены как `Выполнено`.
- В `qa/reopen/backend-reopen-list.md` те же области (`RBAC`, секреты, ссылочная целостность, coverage, k8s) отмечены как незакрытые и требуют re-open.
- Вывод: итог QA-статуса не консистентен, тестировщик не довел финальную синхронизацию отчетов.

## 2) Не закрыт проверочный объем по DoD (фактические прогоны)

Согласно `qa/backlog-verification/verification-report.md`:
- не выполнялся полноценный прогон Jenkins pipeline;
- не выполнялись E2E проверки;
- ряд пунктов проверен только статическим чтением кода/конфигов.

Что не доделано тестировщиком как проверка DoD:
- нет доказательства блокировки merge на lint/coverage через реальный CI run;
- нет подтверждения rollback/rollout поведения в k8s на стенде;
- нет фактической проверки сценариев RBAC (`403`) по ролям на API уровне;
- нет end-to-end подтверждения сценариев FE-04/FE-05.

## 3) Не сформирован единый финальный verdict по backlog

- Нет единого итогового документа с:
  - окончательным статусом каждой задачи;
  - ссылкой на доказательства (логи/скриншоты/команды);
  - списком открытых блокеров.
- Текущие документы дают разные трактовки состояния задач и не могут быть приняты как финальный QA sign-off.

## 4) Что требуется завершить тестировщику

1. Выпустить единую финальную матрицу статусов без противоречий.
2. Подтвердить спорные пункты реальными прогонами (CI/k8s/API), а не только статическим анализом.
3. По каждой задаче backlog приложить артефакты проверки (команда -> результат -> вывод).
4. Согласовать re-open список с финальным отчетом, чтобы не было конфликтующих файлов.

## Краткий вывод

Тестировщик выполнил подготовительную и аналитическую часть, но не довел проверку backlog до полноценного, непротиворечивого QA-закрытия с достаточной доказательной базой.
